# Справочник по генеративным приёмам

M8 имеет целое семейство генеративных функций. Они решают разные музыкальные задачи и не являются взаимозаменяемыми. Ниже каждая описана конкретным рецептом, ясным применением и наиболее частой ошибкой.

**Стратегия:** если генеративная функция не складывается, вероятно, она используется не для той задачи. Сопоставляй технику с целью.

**Ссылки:** M8 Operation Manual v6.5.2 - shortcuts Phrase View (стр. 15), тип модуляции LFO (стр. 20-21), Table View + режимы TIC (стр. 24), Hypersynth (стр. 60).

## 1. Рандомизация Phrase View в режиме выделения

**Применение:** паттерн hi-hat или percussion ощущается слишком жёстким; нужно очеловечивание без ручного написания каждой вариации.

Рецепт:

- [ ] В Phrase View поставь курсор на ноты, которые нужно варьировать.

- [ ] Войди в режим выделения: `[SHIFT]+[OPTION]`.

- [ ] Убедись, что выбрана колонка нот, а не velocity, instrument или FX.

- [ ] Примени один вариант:

  - `[OPTION]+[UP]` либо `[OPTION]+[DOWN]` - случайно меняет значение ноты вверх или вниз;

  - `[OPTION]+[LEFT]` - перебирает режимы заполнения нот;

  - `[OPTION]+[RIGHT]` - рандомизирует ноты И номера запускаемых инструментов.

- [ ] Выйди из режима выделения. Результат теперь записан во фразу.

- [ ] Если он не нравится, немедленно выполни paste комбинацией `[SHIFT]+[EDIT]`, чтобы отменить fill.

**Типичная ошибка:** пытаться рандомизировать колонки volume или FX вместо нот. Fill работает только в колонке нот; в остальных эти кнопки выполняют обычную навигацию.

**Когда применять:** в конце занятия по написанию, когда паттерны ощущаются застывшими. Тридцать секунд randomization вместо десяти минут ручных вариаций.

## 2. Формы LFO Random / Drunk

**Применение:** требуется движение фильтра или другой модуляции, которое никогда не повторяется совершенно одинаково. Развивающиеся текстуры, дышащие pads и непредсказуемый саунд-дизайн.

Две разные формы:

- `RANDOM` - каждый цикл LFO выбирает новое случайное значение: ступенчато, непредсказуемо, скачкообразно;

- `DRUNK` - random walk: каждое новое значение немного отклоняется от предыдущего; движение мягче, органичнее и никогда точно не возвращается.

**Рецепт — развивающийся pad:**

- [ ] Открой pad и перейди в Instrument Modulation View комбинацией `[SHIFT]+[UP]` из Instrument View.

- [ ] Настрой `MOD2`, сохранив `MOD1` для огибающей:

  - `TYPE = LFO`;

  - `DEST = FILTER CUTOFF`;

  - `OSC = DRUNK`;

  - `TRIG = FREE`, чтобы движение продолжалось между нотами;

  - `FREQ` медленная, попробуй `20-40`;

  - `AMT` умеренный, `30-50`.

- [ ] Удерживай ноту: фильтр блуждает.

- [ ] Выбери `OSC = RANDOM` и услышь разницу: скачки против непрерывного дрейфа.

**Tick-варианты:** добавь `T` к форме - `RANDOM T`, `DRUNK T`. Теперь frequency измеряется в тиках вместо шестнадцатых, что даёт гораздо более быструю модуляцию для текстурного саунд-дизайна, а не медленного движения.

**Типичная ошибка:** слишком высокий `AMT`. Random/Drunk на большой глубине звучит хаотично; тонкий диапазон `20-40` обычно полезнее драматического.

**Когда применять:** в любом месте, где статичный параметр должен стать живым: filter; pitch для дрейфующего тонкого vibrato; volume для органической динамики; pan для плавающего stereo image.

## 3. Probability и fill вместе с рандомизацией

**Применение:** «примерно каждый четвёртый цикл паттерна у малого барабана может появляться дополнительная ghost note». Тонкая вариация между циклами без ручного программирования.

Рецепт:

Механизм probability M8 частично находится в режиме выделения Phrase View, см. пункт 1, а частично реализуется FX-командами, доступными через встроенный Effect Command Help View: `[EDIT]+[UP]` либо `[EDIT]+[DOWN]` в любой колонке FX.

- [ ] Открой Effect Command Help и найди команды, связанные с probability, доступные текущему типу инструмента.

- [ ] Набор зависит от типа инструмента; встроенная справка является источником истины.

- [ ] Альтернативный подход: примени рандомизацию нот из пункта 1 к копиям паттерна, затем чередуй их через chain transpose или варианты фразы.

**Типичная ошибка:** ожидать одну универсальную команду probability. M8 предлагает несколько механизмов в зависимости от типа инструмента и изменяемого параметра. Через Effect Command Help проверяй доступное прямо сейчас.

**Когда применять:** на поздней стадии очеловечивания, когда аранжировка уже зафиксирована, но паттерны ещё слишком предсказуемы.

## 4. Режимы Table TIC - отображение ноты, velocity и октавы

Здесь таблицы перестают быть «step-sequencer» и становятся «инструментами, реагирующими на вход».

**Применение:** один слот инструмента должен играть разные звуки в зависимости от ноты, силы удара или октавы.

См. M8 Operation Manual v6.5.2, Table TIC Modes, стр. 24.

- `TIC00` - переход к следующей строке таблицы при каждом запуске инструмента, одна строка на удар ноты;

- `TIC01`–`TICFB` - стандартное воспроизведение с заданным числом тиков на строку;

- `TICFC` - Octave Map, игровая октава отображается на строку таблицы;

- `TICFD` - Velocity Map, velocity отображается на строку;

- `TICFE` - Note Map, значение ноты отображается на строку; `HOP00` в строке `0C` ограничивает диапазон двенадцатью нотами на октаву;

- `TICFF` - продвижение с частотой 200 Hz, очень быстро.

Запись `TICFC-TICFF` используется для FX-команды, но в поле Instrument View выбираются сами hex-значения `FC-FF`.

**Рецепт — барабанный удар, отображающий velocity:**

- [ ] Настрой Sampler с одним drum sample.

- [ ] В Instrument View установи `TABLE TIC = TICFD` - velocity map.

- [ ] Открой таблицу инструмента. Каждая строка теперь соответствует диапазону velocity.

- [ ] Строка `00`: оставь стандартной для самой низкой velocity.

- [ ] Строка `04`: добавь команду `PIT`, чтобы немного поднять высоту среднего удара.

- [ ] Строка `08`: сильнее подними высоту и немного увеличь громкость.

- [ ] Строка `0C`: значительно подними высоту и добавь короткий send reverb через FX-команду.

- [ ] Изменение velocity теперь создаёт настоящие вариации, а не только громкость.

**Рецепт — sample kit, отображающий ноты:**

- [ ] Установи `TABLE TIC = FE` - note map.

- [ ] В строке `0C` добавь `HOP00`, ограничивающий диапазон 12 нотами на октаву, как указано в руководстве.

- [ ] Каждая строка таблицы соответствует ноте. Командами `INS` или другими FX-командами смены инструмента назначь разный звук каждой ноте.

- [ ] Получится один слот «инструмента», воспроизводящий drum kit, разложенный по нотам.

**Типичная ошибка:** забыть выбрать специальный режим `FC/FD/FE`. До этого таблица работает линейно, и никакого отображения входа не происходит.

**Когда применять:** при создании инструментов, выразительно реагирующих на исполнение; особенно важно для finger-drumming kit и sample chain.

## 5. Hypersynth

**Применение:** нужны музыкальные аккордовые прогрессии или scale-aware-воспроизведение без ручного программирования каждого голоса. Подходит для harmonic content: pads, ambient, chord stabs.

См. M8 Operation Manual v6.5.2, Hypersynth, стр. 60. Раздел плотный: выдели отдельные 30 минут.

Общий подход, точные параметры проверяй на устройстве:

- [ ] Установи `TYPE = Hypersynth`.

- [ ] Hypersynth использует Scale проекта, M8 Operation Manual v6.5.2, Scale View, стр. 28, и поддерживает глобальную команду гаммы `SCG`.

- [ ] Изучи параметры Instrument View: тип аккорда, voicing, ступень гаммы и тембральные настройки.

- [ ] Сыграй одну ноту в Phrase View. Hypersynth строит вокруг неё аккорд по своим параметрам.

**Типичная ошибка:** обращаться с Hypersynth как с Wavsynth/Macrosynth. Это другая модель: здесь настраивается генерация аккорда, а не выбирается обычная одиночная волна. Если звучит один тон, настрой параметры аккорда.

**Когда применять:** ambient и harmonic tracks с прогрессиями без программирования каждого голоса; также отлично для stab/chord в более танцевальной музыке.

## 6. Таблицы как арпеджиаторы и генеративные секвенсоры

**Применение:** одна нота Phrase View должна запускать развивающуюся фразу - arpeggio, мелодический riff или автоматически исполняемую последовательность высот и эффектов.

Именно для этого таблицы и были созданы. M8 Operation Manual v6.5.2, стр. 24, описывает их как маленькие секвенсоры, играющие рядом с инструментами, и мощный способ преобразовывать инструменты и композиции - от arpeggio и volume slide до многостадийных envelopes и effects.

**Рецепт — генеративное arpeggio:**

- [ ] У мелодического инструмента установи низкое значение `TABLE TIC`, например `02` или `04`, чтобы таблица играла быстрее фразы.

- [ ] Открой таблицу.

- [ ] В колонке `N`, transpose, введи `00, 04, 07, 0C, 07, 04, 00, -05`: мажорное arpeggio вверх до септимы и обратно.

- [ ] В Phrase View запусти ОДНУ ноту этого инструмента. Таблица сыграет arpeggio.

- [ ] Командами `HOP` замкни подраздел либо перескакивай между строками: arpeggio будет развиваться, а не просто повторяться.

**Рецепт — полиритмическое движение:**

- [ ] В таблице второго инструмента сделай то же, но с ДРУГИМ числом строк: например, через `HOP00` замкни после строки 7, а не 16.

- [ ] Одновременно запусти оба инструмента во фразе. Два arpeggio повторяются с разными периодами и создают polyrhythm.

**Типичная ошибка:** слишком медленный `TABLE TIC`. Если скорость совпадает с tick rate фразы, таблица ощущается как постоянная нота, а не последовательность. Для arpeggio поставь её в два-четыре раза быстрее фразы.

**Когда применять:** генеративная мелодическая композиция. Пиши меньше нот в Phrase View, остальное пусть создаёт таблица. Отлично для IDM, ambient и electronic с генеративным уклоном.

## Комбинации техник

Сила возникает в сочетаниях, а не в изоляции:

- **Random LFO + Table TIC:** барабан с velocity map и Drunk LFO на filter cutoff. Каждый удар немного отличается, а фильтр независимо блуждает.

- **Hypersynth + генеративная таблица:** Hypersynth создаёт аккордовое содержание, таблица - ритмический паттерн chord stab.

- **Рандомизация выделения + таблица с probability:** случайно расставь ноты, затем таблицы создают вариации каждого запуска.

Дисциплина: не объединяй больше двух техник в одном инструменте. Четыре создадут звуковой хаос, который невозможно логически разобрать при проблеме.

## Когда генеративные инструменты вредят

- **У трека нет личности.** Всё написание делегировано случайности, поэтому отсутствует авторский голос. Исправление: chorus/hook оставь намеренным, а генеративность используй только для вариаций и fills.

- **Невозможно повторить понравившийся звук.** Random-формы не используют детерминированный seed. Исправление: когда найден хороший случайный паттерн, заморозь его через render to sample - Selection to Sample, M8 Operation Manual v6.5.2, стр. 48 - и используй семпл.

- **Паттерны дёрганые.** Слишком много randomization. Исправление: уменьши `AMT` LFO, плотность probability или используй Drunk вместо Random.

- **Отдельно прекрасно, в миксе ужасно.** Генеративные элементы борются за один частотный диапазон. Дисциплина [Справочника по сведению](mixing.md) действует и здесь.

## Как изучать этот набор

Не пытайся освоить все шесть техник за одно занятие. План распределяет их по конкретным неделям:

- неделя 2 - формы LFO Random/Drunk как продолжение изучения LFO;

- неделя 4 - рандомизация фраз + probability как продолжение вариации паттерна;

- неделя 7 - режимы Table TIC `FC/FD/FE` + Hypersynth в спокойную неделю библиотеки;

- неделя 8 - таблицы как арпеджиаторы, мелодический shortcut для Проекта 2.

После плана вернись к этому разделу и объединяй. Именно сочетания делают M8 уникально мощным.
