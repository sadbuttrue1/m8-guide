# Неделя 7 - стартовая библиотека инструментов

**Цель:** создать десять собственных инструментов, которые можно будет использовать снова и снова. На этой неделе трека нет: только создание библиотеки.

Это восстановительная неделя между Проектом 1, переданным на неделе 6, и Проектом 2, который начнётся на неделе 8. Занимайся дизайном инструментов без давления результата.

**Ссылки:** M8 Operation Manual v6.5.2 - Instrument View (стр. 16), Instrument Modulation View (стр. 18), Wavsynth (стр. 50), Macrosynth (стр. 52), Sampler (стр. 54), FM Synth (стр. 58), Hypersynth (стр. 60).

**Стратегия:** прежде чем проектировать всё с нуля, разбери один-два существующих инструмента. Открой Community Starter Pack или инструменты laamaa и посмотри, как настроены параметры и слоты модуляции. Затем создай свои варианты.

## Линия 1: техника M8 - создание десяти инструментов

### Общая архитектура каждого инструмента M8

Независимо от `TYPE`, каждый инструмент M8 проходит один и тот же путь сигнала. Между движками меняется только крайний левый раздел. См. M8 Operation Manual v6.5.2, Instrument View, стр. 16, и Modulation View, стр. 18:

**Source > Filter > Amplifier > Mixer sends**, поверх которых работают четыре слота модуляции.

- **Source** - часть, специфичная для движка: `SHAPE` Wavsynth; `SHAPE/TIMBRE/COLOR` Macrosynth; операторы FM; либо `SAMPLE` Sampler. Только этот участок различается между движками.

- **Filter** - тип `FILTER` (`LP/HP/BP/BS/LP>HP/ZDF`), `CUTOFF`, `RES`. Одинаков для всех движков.

- **Amplifier** - `AMP` и `LIM` с вариантами `CLIP/SIN/FOLD/WRAP` для уровня и drive.

- **Mixer sends** - выходы `DRY/MFX/DEL/REV` на глобальные эффекты.

- **Modulation, MOD1-MOD4** - каждый слот может быть `AHD ENV`, `ADSR ENV`, `DRUM ENV`, специально предназначенной для перкуссии, `LFO`, `TRIG ENV` или `TRACKING`, связывающим ноту/velocity с параметром; всё это направляется на любой `DEST`. См. M8 Operation Manual v6.5.2, стр. 20.

Каждый рецепт ниже следует одному порядку: выбери source, сформируй amp envelope, установи filter, затем добавь modulation. Один раз освой разделы Filter/Amp/Mixer/Mod: они одинаковы во всех десяти инструментах.

### Подготовка

- [ ] Выбери систему имён. Например: `EG-Bass-Sub`, `EG-Bass-Acid`, `EG-Lead-Pluck`. Поле `NAME` в M8 имеет ограниченную длину, поэтому имена должны быть короткими.

- [ ] Сохраняй каждый инструмент через Instrument View > `SAVE`. Файлы попадут в `/Instruments/` на SD-карте.

### Басовые инструменты

- [ ] **Sub bass** — `EG-Bass-Sub`

	**Назначение:** фундамент под всем остальным - чистая масса низких частот, которую скорее ощущаешь, чем слышишь, без гармоник, конфликтующих с бочкой или серединой.

	**Построение:**

	- `TYPE = Wavsynth`, `SHAPE = SINE`; либо Macrosynth `SINE TRIANGLE` для чуть более плотного тела, см. M8 Operation Manual v6.5.2, стр. 76. Синус почти не имеет гармоник и потому не мешает другим звукам.

	- `MOD1 ADSR > VOLUME`, `ATK=00 DEC=20 SUS=60 REL=20`. Быстрая атака ставит бас точно на долю; умеренный sustain позволяет нотам удерживать заданную длину.

	- Оставь `FILTER` открытым для чистого синуса: гармоник для среза нет, фильтру нечего делать.

	- Держи `AMP` умеренным и не используй drive через `LIM`: distortion добавляет гармоники, которых у чистого sub быть не должно.

	- Instrument EQ: `LOWCUT` ниже 40 Hz, заранее подготавливающий совместимость с бочкой.

	**Типичная ошибка:** drive или яркая форма выращивают гармоники, конфликтующие с бочкой и загрязняющие low-mid. Оставь sub чистым, а transient отдай бочке.

- [ ] **Acid bass** — `EG-Bass-Acid`

	**Назначение:** хлюпающая басовая линия в духе 303, движущаяся под beat; filter sweep сам становится hook.

	**Построение:**

	- `TYPE = Macrosynth`, `SHAPE` - одна из saw-моделей, например `SAW SQUARE` или `SAW SYNC`. См. M8 Operation Manual v6.5.2, стр. 76. Пилообразная волна богата гармониками, поэтому резонансному фильтру есть с чем работать.

	- `FILTER = LP`, `CUTOFF` в нижней или средней области, примерно `50`, `RES` высокий, примерно `B0`. Именно resonance создаёт squelch. Начинай с низкого cutoff, чтобы огибающей было куда открывать фильтр.

	- `MOD1 ADSR > CUTOFF`, `ATK=00 DEC=30 SUS=00 AMT=60`. Это filter pluck на каждой ноте и сердцевина acid-звука.

	- `MOD2 LFO > CUTOFF`, `OSC=TRI FREQ=08 AMT=20`. Медленное покачивание поверх pluck создаёт движение масштаба такта.

	- **Таблица:** именно здесь живут glide и изменения высоты 303. За высоту отвечают две разные команды.

	- `PIT XX` смещает высоту ноты по полутонам, M8 Operation Manual v6.5.2, стр. 75. `PIT 0C` подбрасывает строку на октаву; верхняя половина диапазона `80-FF` смещает вниз. Это ступенчатый скачок, а не slide. Команда квантуется к гамме, см. M8 Operation Manual v6.5.2, Scale View, стр. 28, поэтому смещение привязывается к scale дорожки. Добавь одну-две строки `PIT` для октавного прыжка или быстрого accent-wail перед следующей нотой.

	- `PSL XX` - pitch slide, то есть portamento, - создаёт настоящее плавное glide между нотами. Значение измеряется в тиках, см. M8 Operation Manual v6.5.2, стр. 71: чем оно выше, тем медленнее скольжение. Распространённое значение acid glide - `PSL 06-07`; инструмент работает legato, без retrigger, поэтому последовательные ноты перетекают друг в друга, а не получают новый pluck.

	- **Где ставить PSL:** команда скользит от предыдущей ноты, поэтому должна сработать вместе с нотой назначения - в той же строке, куда выполняется slide, а не в исходной. Есть два варианта. Во фразе поставь `PSL` на строке целевой ноты и убери с неё номер инструмента: получится legato без нового pluck и slide только выбранных нот - реалистичный способ 303. Либо помести `PSL` в строку `00` таблицы инструмента: тогда автоматически скользит каждая сыгранная им нота. При редактировании нижняя строка справки показывает, сколько шагов займёт slide; увеличивай значение, пока длительность не совпадёт с промежутком между двумя нотами. Для линии, близкой к 303, оставь `PSL` в таблице и ставь `KIL03` на шаг перед любой нотой, в которую **не нужно** скользить: slide останется только на связанных или акцентированных нотах.

	- Instrument EQ: `LOWCUT` ниже 40 Hz.

	**Типичная ошибка:** `RES` слишком низок - squelch отсутствует. `CUTOFF` постоянно слишком высок - огибающей некуда двигаться, и pluck исчезает.

- [ ] **FM bass** — `EG-Bass-FM`

	**Назначение:** бас с атакой и металлическими гармониками, которые недоступны субтрактивному синтезу; подходит для DnB, neuro и electro, где басу нужен характер, а не только масса.

	**Построение с чистого патча, без пресетов:** весь звук фактически создают два оператора. Carrier слышен, а modulator колеблет его высоту настолько быстро, что это превращается в тембр. Настрой эту пару, а два остальных оператора заглуши.

	- `TYPE = FM Synth`, M8 Operation Manual v6.5.2, стр. 58. Оставь первый `ALGO`, `A>B>C>D (00)`: единственную цепочку из четырёх операторов. Стрелка означает «модулирует», поэтому последний оператор D является carrier - именно его слышно, - а C его модулирует.

	- **Carrier, оператор D:** форма `SIN`, `RATIO 1.00`, `LEV` полностью. Это основной тон. `RATIO 1.00` воспроизводит нажатую ноту, `2.00` - на октаву выше, `0.50` - на октаву ниже. См. M8 Operation Manual v6.5.2, стр. 58.

	- **Modulator, оператор C:** форма `SIN`, `RATIO 1.00`. Его `LEV` задаёт величину FM, то есть index: при `00` слышен чистый синус; с подъёмом значения накапливаются гармоники. Пока поставь примерно на треть диапазона: позже это станет пиком огибающей.

	- **Заглуши A и B:** у обоих `LEV=00`, чтобы звучала только пара `C>D`. Получился чистый двухоператорный FM-бас.

	- **Выбери тембр через RATIO модулятора.** Целочисленные отношения остаются гармоничными и музыкальными: `1.00` - округлое и тёплое звучание; `2.00/3.00` - ярче и полее. Нецелое отношение, например `1.41`, становится звенящим и металлическим: отлично для атаки neuro/DnB, но неверно для чистого sub. Причина разбирается в линии 2.

	- **Заставь тембр развиваться:** именно это превращает статический FM-тон в бас. В Modulation View, M8 Operation Manual v6.5.2, стр. 18, установи `MOD1 = ADSR`, `ATK=00 DEC=30 SUS=00`. Затем во внутреннем слоте `MOD` оператора C направь `MOD1 > LEV`. Теперь уровень C резко поднимается на атаке и затухает обратно к `00`: назначение `LEV` проводит оператор от нуля до заданного уровня, см. M8 Operation Manual v6.5.2, FM Synth, стр. 58. Яркость FM расцветает, затем исчезает почти до чистого тона. Яркий «pock» поверх чистого хвоста - характерная форма баса DX/FM. Если гармоники должны оставаться на удерживаемой ноте, подними `SUS`.

	- **Необязательный grit:** подними `FB` оператора C либо направь вторую огибающую `MOD2 ADSR > C FBK`. Feedback разлохмачивает синус в металлический край, недоступный субтрактивному синтезу.

	- Instrument EQ: `LOWCUT` ниже 40 Hz.

	**Типичная ошибка:** слишком высокий `LEV` модулятора превращает всё в чистый шум. FM быстро становится резким; уменьши значение, пока высота снова не начнёт ясно читаться. Если звук стал расстроенным или колокольным без такого намерения, отношения `RATIO` не попадают в целые числа.

### Лидирующие и мелодические инструменты

- [ ] **Pluck lead** — `EG-Lead-Pluck`

	**Назначение:** короткие ударные мелодические stabs - arps, plucks и ритмическая верхняя линия, движущая трек.

	**Построение:**

	- `TYPE = Macrosynth`, модель `PLUCKED`, M8 Operation Manual v6.5.2, стр. 77, для готовой физики щипковой струны; либо любая saw-модель или Wavsynth `SAW`, если хочется формировать звук вручную. `PLUCKED` выполняет работу сам, пила оставляет полный контроль.

	- `MOD1 ADSR > VOLUME`, `ATK=00 DEC=10 SUS=00 REL=08`. Нулевой sustain и быстрый decay создают ударный pluck. Именно `SUS=00` сохраняет краткость.

	- `MOD2 ADSR > CUTOFF`, `ATK=00 DEC=30 SUS=00 AMT=60`. Фильтр быстро закрывается вместе с затуханием ноты и добавляет переход от яркого к тёмному поверх амплитудной формы.

	- `FILTER = LP`, `CUTOFF` в средней области, чтобы огибающей cutoff было куда двигаться.

	- Instrument EQ: `LOWCUT` ниже 100-200 Hz.

	**Типичная ошибка:** `SUS` выше `00` заставляет ноту звенеть вместо pluck. Если получается pad, sustain слишком высок.

- [ ] **Pad** — `EG-Pad`

	**Назначение:** длительная гармоническая подложка, заполняющая пространство за лидом и склеивающая раздел.

	**Построение:**

	- `TYPE = Macrosynth`, мягкая модель, например `MORPH`, M8 Operation Manual v6.5.2, стр. 76. Pad нужен спокойный источник, а не жужжащая пила.

	- `MOD1 ADSR > VOLUME`, `ATK=60 DEC=00 SUS=7F REL=A0`. Медленная атака, полный sustain и длинный release заставляют звук набухать и исчезать, а не бить.

	- `MOD2 LFO > CUTOFF`, `OSC=SIN FREQ=20 AMT=20`. Медленное движение фильтра позволяет pad дышать, а не стоять неподвижно.

	- `FILTER = LP`, `CUTOFF` ниже середины: pad остаётся за лидом, а не поверх него.

	- Instrument EQ: `LOWCUT` ниже 200 Hz, срез 200-500 Hz против мути.

	**Типичная ошибка:** слишком быстрая атака превращает pad в stab и заставляет конкурировать с лидом. Если начало ноты отчётливо слышно, удлини `ATK`.

- [ ] **Stab/chord** — `EG-Stab`

	**Назначение:** ритмические аккордовые удары - house/garage stabs, гармоническая пунктуация между мелодическими фразами.

	**Построение:**

	- `TYPE = Macrosynth`, аккорд играется на нескольких дорожках; либо Hypersynth, M8 Operation Manual v6.5.2, стр. 60, который создаёт аккорд из одной ноты. Hypersynth избавляет от ручного voicing; см. линию 3, вариант B.

	- `MOD1 ADSR > VOLUME`, `ATK=00 DEC=18 SUS=00 REL=10`. Быстрая атака, короткий decay и отсутствие sustain дают плотный stab, а не удерживаемый аккорд.

	- `FILTER = LP`, `CUTOFF` в средней области, немного `RES`: к переднему краю аккорда добавляется pluck-snap.

	- Добавь короткий send `REV` или `DEL`: небольшой хвост помогает stab занять место.

	- Instrument EQ: `LOWCUT` ниже 150 Hz.

	**Типичная ошибка:** длинные decay или sustain размазывают stabs друг в друга и лишают ритмического удара.

### Барабанные инструменты

- [ ] **Kick** — `EG-Drum-Kick`

	**Назначение:** transient и масса, удерживающие весь beat.

	**Построение:**

	- `TYPE = Sampler` с семплом бочки - самый простой путь; либо FM Synth для синтезированной бочки с точной настройкой высоты и punch. Семпл быстрее, FM позволяет всё подобрать.

	- Для синтеза: `MOD1 DRUM ENV > PITCH`, быстрый sweep сверху вниз. Падение высоты и создаёт «thump». `DRUM ENV` специально разработана для перкуссии и резче ADSR. См. M8 Operation Manual v6.5.2, стр. 20.

	- `MOD2 DRUM ENV > VOLUME`, короткая. Это огибающая тела, определяющая длину бочки.

	- Оставь звук монофоническим и коротким. Длинный хвост бочки съедает headroom, необходимый басу.

	- Instrument EQ: подъём 60-80 Hz, срез 200-400 Hz.

	**Типичная ошибка:** слишком медленный pitch sweep слышится как «boing», а не удар. Ускорь decay огибающей высоты.

- [ ] **Snare** — `EG-Drum-Snare`

	**Назначение:** треск backbeat - шумовое тело плюс тональный snap.

	**Источник, выбери один:** малый барабан состоит из шума и настроенной оболочки, поэтому нужны обе составляющие.

	- **Sampler с семплом snare** - самый простой вариант.

	- **Два слоя Wavsynth:** один инструмент `NOISE` для тела, второй `SINE/TRIANGLE` для тонального snap. M8 не умеет складывать слои внутри одного инструмента; здесь «layer» означает поместить инструменты на две дорожки и запускать одну ноту в одной строке Phrase. Модель «шум + оболочка» становится наглядной ценой второй дорожки.

	- **Один FM Synth:** эффективный путь с одним инструментом, согласованный с синтезированной бочкой выше. Выбери последний `ALGO` - additive mode, где все четыре оператора идут параллельно на выход; см. M8 Operation Manual v6.5.2, стр. 58. У одного оператора подними `FB` до максимума для шумового тела: именно предельный feedback создаёт шум в FM M8. Второму оператору назначь `SINE/CLICK` и через `RATIO` настрой примерно на 200 Hz для тонального snap. Сбалансируй части через `LEV`. Заводской clap M8 использует тот же приём с FM-шумом от максимального feedback.

	- `MOD1 DRUM ENV` либо `ADSR > VOLUME`, короткий decay, без sustain. Snare - быстрый burst, а не длительный тон.

	- `MOD2 TRACKING > VOLUME`, `SRC=VELOCITY`. Низкая velocity даёт ghost notes, высокая - сильный backbeat, отчего snare ощущается живым. См. M8 Operation Manual v6.5.2, стр. 20.

	- `FILTER = BP` или `HP` на шумовом слое, чтобы сосредоточить crack в верхней середине.

	- Instrument EQ: `BELL` с подъёмом около 200 Hz для тела и около 5 kHz для snap.

	**Типичная ошибка:** один шум без тона даёт «pfft» без crack. Добавь или подними тональный слой либо тело около 200 Hz.

- [ ] **Closed hat** — `EG-Drum-Hat-C`

	**Назначение:** высокочастотный хронометр, движущий groove.

	**Построение:**

	- `TYPE = Wavsynth NOISE` либо Sampler. Хай-хэты являются отфильтрованным шумом, а noise Wavsynth не требует загрузки семпла.

	- `MOD1 DRUM ENV/ADSR > VOLUME`, `ATK=00 DEC=04 SUS=00 REL=02`. Очень короткая огибающая создаёт закрытый «tick».

	- `MOD2 TRACKING > VOLUME`, `SRC=VELOCITY`. Именно вариация velocity заставляет хай-хэты groove, а не звучать пулемётной очередью.

	- `FILTER = HP`, высокий `CUTOFF`: убирает низкочастотный гул и оставляет hat наверху.

	- Instrument EQ: `LOWCUT` 300 Hz, подъём `HI.SHELF` выше 8 kHz.

	**Типичная ошибка:** слишком длинный decay заставляет закрытый hat звенеть как открытый. Укороти `DEC/REL`.

- [ ] **Open hat** — `EG-Drum-Hat-O`

	**Назначение:** подъём на off-beat, отвечающий закрытому хай-хэту.

	**Построение:**

	- Начни с копии закрытого hat. Оба должны иметь один тембр и различаться только длиной, чтобы восприниматься единым kit.

	- Удлини огибающую: `DEC=20 REL=10`. Более длинный хвост - единственное, что делает hat «открытым».

	- Необязательно настрой choke через `TRIG ENV`, чтобы закрытый hat обрывал хвост открытого. Настоящий хай-хэт не может продолжать звенеть после того, как нога закрыла педаль. `TRIG ENV` - огибающая AHD с `ATK/HOLD/DEC`, запускаемая другим инструментом или дорожкой, а не тем, на котором она находится. Она биполярна и может толкать `DEST` не только вверх, но и вниз. См. M8 Operation Manual v6.5.2, стр. 20-21. Отрицательное движение и создаёт choke.

	- На открытом hat добавь слот `MOD > TRIG ENV`, `DEST=VOLUME` и отрицательный `AMT`, достаточно сильный, чтобы мгновенно опустить громкость в ноль.

	- Установи `SRC` на номер инструмента закрытого hat в диапазоне `00-7F` либо на его дорожку: `80-87` соответствуют Tracks 1-8. Тогда любой звук на этой дорожке заглушает открытый hat.

	- Сформируй duck: `ATK=00` для мгновенного среза, затем достаточно длинные `HOLD/DEC`, чтобы хвост оставался заглушённым до того момента, когда он и сам должен был исчезнуть.

	- Теперь каждый удар закрытого hat опускает звенящий открытый hat до тишины, как настоящая закрывающаяся педаль.

	- Instrument EQ: такой же, как у закрытого hat.

	**Типичная ошибка:** другой тембр открытого hat разрушает ощущение единого инструмента. Сначала копируй, затем меняй только длину.

### Бонус

- [ ] **Noise sweep** — `EG-FX-Sweep`

	**Назначение:** переходный riser/faller, закрывающий шов между разделами.

	**Построение:**

	- `TYPE = Wavsynth`, `SHAPE = NOISE`.

	- Автоматизируй `CUTOFF` от закрытого к открытому длинной `AHD ENV` с длинным `ATK` либо ramp в таблице, распределённым на много строк. Медленное открытие фильтра создаёт «whoosh».

	- `FILTER = BP` для характера ветра либо `LP` для более полного sweep.

	- Запускай один раз в конце раздела: это one-shot-переход, а не loop.

	**Типичная ошибка:** слишком короткий ramp создаёт быстрый «pfft» вместо нарастающего riser. Распредели движение cutoff на большее число строк или тиков.

### Проверка обратным разбором

- [ ] Загрузи [Community Starter Pack](https://archive.org/download/ChipmusicResources/M8_Community_SD-card_Starter_Pack.7z) на SD-карту.

- [ ] Открой несколько инструментов и изучи слоты модуляции. Заимствуй то, что нравится.

- [ ] Также открой [инструменты laamaa](https://github.com/laamaa/m8i).

## Линия 2: основа синтеза - основы FM

**Цель:** перестать бояться FM Synth. Выполни до рецепта FM-баса выше либо параллельно ему. Это тот же двухоператорный патч, но теперь он исследуется свободно, а не строится ради конкретного результата.

- [ ] Открой тип инструмента FM Synth: M8 Operation Manual v6.5.2, стр. 58. Это четырёхоператорный FM с 12 алгоритмами.

- [ ] Концепция: один оператор, modulator, изменяет частоту другого, carrier, настолько быстро, что колебание воспринимается как тембр, а не слышимое vibrato. Отношение `RATIO` модулятора к carrier определяет, какие гармоники появятся; его `LEV`, то есть FM index, задаёт их силу.

- [ ] Построй голый двухоператорный патч из рецепта FM-баса: `ALGO 00`; carrier D - `SIN`, `RATIO 1.00`; modulator C - `SIN`; A и B заглушены через `LEV=00`. Теперь остаётся всего одна ручка - `RATIO` оператора C, на которой хорошо слышно, что делает FM.

- [ ] Меняй `RATIO` оператора C: целые отношения `1.00`, `2.00`, `3.00` дают гармоничное музыкальное звучание; нецелое `1.41` - звенящее, колокольное, металлическое.

- [ ] Проведи `LEV` оператора C от `00` вверх. `00` даёт чистый синус; более высокие значения добавляют гармоники. Это FM index - важнейший регулятор FM.

- [ ] Освой особенность маршрутизации. Чтобы тембр двигался со временем, огибающая не направляется на глобальный `DEST`. Сначала в M8 Operation Manual v6.5.2, Modulation View, стр. 18, настрой `MOD1` как ADSR, затем назначь её во внутреннем слоте `MOD` оператора, например `C > LEV`, как описано в FM Synth на стр. 58 того же руководства. Это именно шаг «заставить развиваться» в рецепте FM-баса и единственное действие, устроенное иначе, чем у остальных движков.

- [ ] Не стремись к мастерству. Задача - только избавиться от страха.

## Линия 3: генеративное исследование

Неделя библиотеки подходит для спокойного исследования функций без риска. Когда нет давления трека, можно поиграть с тем, что раньше не складывалось.

Полный контекст находится в [Справочнике по генеративным приёмам](../reference/generative.md), пункты 4 и 5. Выбери один или несколько вариантов; для завершения недели библиотеки они не обязательны.

### Вариант A: режимы Table TIC - инструменты, отображающие velocity или ноты

Так выглядят таблицы, когда перестают быть step-sequencer и превращаются в инструменты, реагирующие на вход. См. M8 Operation Manual v6.5.2, Table TIC Modes, стр. 24.

**Примечание о прошивке:** в 6.5.x `TIC:FD` перезапускается при изменении *ноты*, а не velocity, поэтому инструмент с velocity map может вести себя хаотично. Прошивка 6.6.0 исправляет это вместе со связанным сбоем повторного запуска `TIC:FC`/`TIC:FE`. Если рецепты сопротивляются, сначала проверь версию прошивки — см. [Справочник по прошивкам](../reference/firmware.md).

**Где это находится - именно эту часть часто не замечают:** отдельного меню «TIC type» нет. `TABLE TIC` - единственное числовое поле Instrument View. Обычно оно остаётся на `01`, одна строка таблицы на tick; `02` означает два тика и так далее. См. M8 Operation Manual v6.5.2, стр. 23. Специальные режимы расположены в верхней части того же поля: прокрути значение до конца за диапазон числа тиков, чтобы получить `FC` = octave map, `FD` = velocity map, `FE` = note map, `FF` = 200 Hz. См. M8 Operation Manual v6.5.2, стр. 24. Поэтому «установить TICFD» фактически означает «прокрутить значение TABLE TIC до FD». M8 не показывает именованные варианты, только верхние hex-значения поля. Запись `TICxx` используется в форме FX-команды: если поставить `TICFD` в FX-колонку фразы или таблицы, она делает то же самое и переопределяет поле инструмента. См. M8 Operation Manual v6.5.2, стр. 23.

Рецепт барабанного удара, отображающего velocity:

- [ ] Выбери один из стартовых барабанных инструментов: kick или snare.

- [ ] В Instrument View прокрути `TABLE TIC` до `FD`, режима velocity map.

- [ ] Открой таблицу инструмента. Теперь каждая строка соответствует диапазону velocity.

- [ ] Строка `00`: оставь стандартной, она отвечает самым тихим ударам.

- [ ] Строка `04`: добавь небольшой `FIN`. Средняя velocity становится чуть плотнее и выше, но смещение меньше полутона не расстраивает звук.

- [ ] Строка `08`: больше `FIN`, небольшой подъём громкости FX-командой `VOL`, см. пояснение ниже, и немного `CUTOFF`, чтобы открыть тембр.

- [ ] Строка `0C`: `FIN` наверху диапазона и короткий send `REV` через FX-команду. Самые сильные удары ощущаются «сильнее» благодаря тембру, а не скачку высоты.

- [ ] Теперь изменение velocity создаёт настоящие вариации барабана, а не только громкости.

- [ ] Сохрани как новый инструмент, например `EG-Drum-Snare-V` для версии, реагирующей на velocity.

**Почему FIN, а не PIT, на настроенном барабане:** `PIT` движется целыми полутонами и квантуется к гамме, см. M8 Operation Manual v6.5.2, стр. 28. На snare с узнаваемой настроенной оболочкой сильный удар перескакивает к явно другой высоте и звучит расстроенным. `FIN` смещает меньше чем на полутон, см. M8 Operation Manual v6.5.2, стр. 75, и создаёт естественную вариацию без эффекта «неправильной ноты». Большую часть различия тихого и сильного удара перенеси в тембр: `CUTOFF`, send `REV/DEL`, а не высоту. Для ненастроенного источника - noise hat или FX - большие скачки `PIT` допустимы.

**О громкости таблицы - колонка V относительна, это не boost:** значение `V` таблицы умножается на `V` фразы, см. M8 Operation Manual v6.5.2, стр. 24. Оно способно только пропорционально масштабировать входной уровень, а не добавить фиксированную величину. Для настоящего смещения громкости в строке используй FX-команду `VOL XX` - «offset the instrument volume», M8 Operation Manual v6.5.2, стр. 75 - в одной из трёх колонок FX. Поэтому рецепт выше поднимает громкость командой FX, а не колонкой `V`.

**Типичная ошибка:** забыть изменить `TABLE TIC` либо искать отдельный подписанный «type». Пока значение `TABLE TIC` не поднято в диапазон `FC/FD/FE`, таблица линейно воспроизводится с заданной скоростью tick, и отображение входа не работает.

### Вариант B: Hypersynth - генерация аккордов

См. M8 Operation Manual v6.5.2, стр. 60. Hypersynth отличается от изученных движков: он создаёт аккорды из одиночных нот, а не один тон.

- [ ] Открой пустой слот инструмента и установи `TYPE = Hypersynth`.

- [ ] Потрать 15-20 минут на изучение параметров в Instrument View. Не пытайся закончить звук; просто пойми действие каждого параметра.

- [ ] Hypersynth учитывает Scale проекта, M8 Operation Manual v6.5.2, стр. 28. Установи гамму на дорожке FX-командой `SCA` либо глобально через `SCG`.

- [ ] Сыграй одну ноту в Phrase View. Hypersynth построит вокруг неё аккорд.

- [ ] Попробуй разные гаммы. Одна и та же нота создаёт разные аккорды в зависимости от scale.

- [ ] Если понравилось, сохрани в библиотеку как `EG-Hyper-Chord` или похожим именем.

- [ ] Если нет - ничего страшного: по крайней мере ты больше не боишься открыть этот движок.

**Типичная ошибка:** обращаться с Hypersynth как с Wavsynth и выбирать форму волны. Это модель генерации аккордов: здесь настраивается построение аккорда, а не составляющие его волны. Если нота Hypersynth звучит одиночным тоном, отрегулируй параметры аккорда.

### Вариант C: нарезанный drum kit - один Sampler, много звуков

Это подход drum rack, намеренно пропущенный на неделе 1. Теперь, когда отдельные барабанные инструменты уже работают, его стоит исследовать.

Рецепт хроматического воспроизведения слайсов:

- [ ] Найди или создай drum chain `.wav` из нескольких ударов - один файл, где последовательно соединены kick, snare, hat и другие звуки. Браузерный инструмент [DigiChain](https://brian3kb.itch.io/digichain) создаёт такие файлы и записывает совместимые с M8 маркеры слайсов.

- [ ] Открой пустой слот: `TYPE = Sampler`; в `SAMPLE` загрузи drum chain `.wav`.

- [ ] Нарежь семпл. Открой Sample Editor из загруженного файла Sampler и создай маркеры процессом `SLICE`. См. M8 Operation Manual v6.5.2, стр. 56-57. Обычно используются два режима:

  - `SLICE:AUTO` - режет по transient. Лучше всего, когда удары имеют отчётливые пики атаки, как большинство drum kit;

  - `SLICE:SILENC` - режет по паузам. Лучше, когда удары разделены явной тишиной, как one-shot-записи с промежутками;

  - `SLICE:[0-128]` также делит файл максимум на 128 равных частей, но для chain с ударами разной длины `AUTO` или `SILENCE` дают лучший результат.

- [ ] Запускай слайсы хроматически нотами. В Instrument View установи параметр Sampler `SLICE = FILE`: воспроизводятся созданные маркеры, привязанные к нотам начиная с `C-1`. См. M8 Operation Manual v6.5.2, стр. 54 и 57. Разные ноты Phrase View - например `C-4`, `C#4`, `D-4` - теперь запускают последовательные слайсы. Числовое значение `SLICE` вместо `FILE` выполняет равномерную нарезку и игнорирует маркеры `AUTO/SILENCE`.

- [ ] Построй барабанный паттерн, меняя ноты вместо номеров инструментов, как при игре на drum rack.

Когда выбирать этот способ вместо отдельных Sampler с недели 1:

- **Отдельные Sampler** - проще, дают больше свободы каждому звуку и чаще используются на M8.

- **Sliced kit** - экономит слоты инструментов, когда звуков много, а свободных слотов мало. Также отлично подходит для chopped breakbeat и обработки вокальных фраз.

**Типичная ошибка:** загрузить нарезанную chain в Sampler при стандартном `SLICE 00OFF` и ожидать поведения drum kit. В `00OFF` инструмент воспроизводит файл целиком и транспонирует его нотой. Нужны одновременно маркеры через `AUTO` или `SILENCE` И параметр `SLICE = FILE`, чтобы ноты отображались на маркеры.
