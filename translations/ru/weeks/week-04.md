# Неделя 4 - retrigger, arpeggio и принцип LFO

**Цель:** освоить третью технику класса таблиц. Проект 1 достигает состояния черновика примерно в 60 тактов или 15 строк - около двух минут при 120 BPM, - но на этой неделе ещё не завершается. Настоящие сведение и финализация выполняются на неделях 5-6.

Это последняя неделя чистой техники перед фазой 2 - применением.

Обе команды описаны в M8 Operation Manual v6.5.2: `ARP` - стр. 8 и 28; `RET` - Sequencer FX Commands, стр. 69, «Retrigger the current row with volume ramping». Встроенный Effect Command Help View остаётся самым быстрым способом проверить, допустима ли команда для текущего типа инструмента.

**Ссылки:** M8 Operation Manual v6.5.2 - Effect Command Help View (стр. 48), Sequencer FX Commands (стр. 69), Instrument FX Commands (стр. 75), Common Groove Examples (стр. 81).

Значения `RET` считаются в **тиках**, а строка фразы равна шести тикам: `RET 03` срабатывает дважды за строку, а `RET 06` — один раз и поэтому кажется бездействующим. Если значения тиков, groove и swing пока непонятны, сначала прочитай короткий [Справочник по таймингу](../reference/timing.md).

## Линия 1: техника M8 - retrigger и arpeggio

### Проверка перед использованием

- [ ] В любой колонке FX в Phrase View или Table View нажми `[EDIT]+[UP]` либо `[EDIT]+[DOWN]`, чтобы открыть Effect Command Help View. См. M8 Operation Manual v6.5.2, стр. 48.

- [ ] Просмотри доступные команды. Представление в реальном времени показывает, какие из них допустимы для текущего типа инструмента.

- [ ] Убедись в наличии `ARP`: arpeggio точно существует, пример `ARP37` приведён в M8 Operation Manual v6.5.2, стр. 8.

- [ ] Убедись, что `RET` - retrigger из M8 Operation Manual v6.5.2, Sequencer FX Commands, стр. 69 - показан в справке для выбранного инструмента.

### Арпеджио

`ARP37` означает arpeggio с первым интервалом +3 полутона и вторым +7 полутонов. Две цифры задают два интервала. См. M8 Operation Manual v6.5.2, стр. 8.

- [ ] В Проекте 1 добавь `ARP` на ноту chord stab мелодического инструмента.

- [ ] Попробуй `ARP47` - мажорное трезвучие: +4, большая терция, и +7, квинта; `ARP37` - минорное трезвучие: +3, малая терция, и +7; `ARP57` - sus4: +5, кварта, и +7.

- [ ] `ARP` учитывает гамму, заданную командой `SCA`. См. M8 Operation Manual v6.5.2, стр. 28. Это помогает удерживать арпеджио в тональности.

### Retrigger и rolls

- [ ] Используй `RET` для snare roll, глитчевых паттернов хай-хэта и рубленого tracker-звучания. `RET XY` повторно запускает текущую строку с ramp громкости на протяжении `Y` тиков. См. M8 Operation Manual v6.5.2, стр. 69.

- [ ] Добавь retrigger на один удар малого барабана в Проекте 1, например как fill с snare roll.

- [ ] Попробуй его на хай-хэте, чтобы получить stutter.

### Probability и fills: генеративная вариативность

Полный контекст находится в [Справочнике по генеративным приёмам](../reference/generative.md), пункты 1 и 3.

В режиме выделения Phrase View M8 имеет встроенную рандомизацию. См. M8 Operation Manual v6.5.2, стр. 15. Это генеративный инструмент для финального очеловечивания: паттерны ощущаются живыми без ручного написания вариантов.

Рецепт очеловечивания слишком жёсткого паттерна хай-хэта:

- [ ] В Phrase View поставь курсор на ноты хай-хэта, которые нужно варьировать.

- [ ] Войди в режим выделения: `[SHIFT]+[OPTION]`.

- [ ] Важно: должна быть выбрана колонка нот, а не velocity или номер инструмента. Режимы fill работают только с колонкой нот.

- [ ] По очереди попробуй:

  - `[OPTION]+[UP]` или `[OPTION]+[DOWN]` - случайно меняет ноты вверх или вниз, создавая тонкую вариацию высоты;

  - `[OPTION]+[LEFT]` - перебирает режимы заполнения нот;

  - `[OPTION]+[RIGHT]` - рандомизирует ноты И номера запускаемых инструментов.

- [ ] Выйди из режима выделения. Результат зафиксируется.

- [ ] Если результат не нравится, немедленно выполни paste комбинацией `[SHIFT]+[EDIT]`, чтобы отменить fill. Руководство прямо указывает: «После выхода из режима выделения вслед за fill-действием выполните paste для отмены».

**Типичная ошибка:** попытка использовать эти комбинации на колонках velocity, инструмента или FX. Они работают только в колонке нот. В остальных колонках те же кнопки выполняют обычную навигацию.

Попробуй на Проекте 1:

- [ ] Найди один паттерн, который ощущается слишком жёстким. Обычно это хай-хэты.

- [ ] Примени рандомизацию, сделай render и послушай.

- [ ] Если стало лучше - оставь; если хуже - отмени. Никаких обязательств.

## Линия 2: основа синтеза - понимание LFO

**Цель:** осознать, что LFO недели 2 и табличная модуляция недели 2 относятся к одному семейству.

LFO - это всё, что:

- медленно колеблется;

- модулирует назначение.

Три свойства: скорость `FREQ`, глубина `AMT`, назначение `DEST`.

- [ ] Возьми инструмент Wavsynth. В Instrument Modulation View одновременно настрой два слота LFO:

  - `MOD1: LFO > PITCH`, медленная скорость, малая глубина = тонкое vibrato;

  - `MOD2: LFO > VOLUME`, более высокая скорость, средняя глубина = tremolo.

- [ ] Одна концепция LFO при разных назначениях даёт совершенно разные эффекты.

- [ ] Теперь понятно: таблица из «Способа B» недели 2 была ручным ступенчатым LFO. Это то же семейство.

## Линия 3: принцип аранжировки - спроектированные переходы

**Цель:** переход A > B должен содержать движение, а не просто монтажный стык.

- [ ] Добавь в Проект 1 один спроектированный переход между A и B. Выбери один вариант:

  - snare roll с командой retrigger из линии 1;

  - filter sweep: автоматизируй DJ filter `DJF` в Mixer View либо используй таблицу на инструменте noise sweep;

  - нисходящее движение высоты басовой ноты: применяй `PIT` в последовательных строках таблицы;

  - beat repeat или stutter через retrigger;

  - тишина: один пустой такт прямо перед вступлением B.

- [ ] Выбери один вариант. Не складывай пять одновременно.
