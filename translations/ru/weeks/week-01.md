# Неделя 1 — возвращение к M8

**Цель:** убрать трение холодного старта и восстановить мышечную память. Никаких новых техник - докажи, что устройство по-прежнему работает для тебя. Установка: намеренно низкая планка. Успех = включить M8, воспользоваться им и что-нибудь отрендерить.

**Ссылки:** M8 Operation Manual v6.5.2 - Getting Started (стр. 5), Navigation (стр. 6), Global Key Shortcuts (стр. 7), Loading a Demo Song (стр. 9), Song View (стр. 10), Chain View (стр. 12), Phrase View (стр. 14), Mixer View (стр. 31), Render View (стр. 47).

## Линия 1: техника M8 - возвращение

### Включение и восстановление навыка

- [ ] Если батарея разряжена, заряди M8. Включи кнопкой питания справа, удерживая её 1 секунду. См. M8 Operation Manual v6.5.2, Powering Up, стр. 3.

  - Если M8 не загружается, семпл не открывается или карта работает неправильно, решение почти наверняка есть в [Справочнике по диагностике](../reference/troubleshooting.md). Не отдавай этому всё занятие.

- [ ] Project View находится над Song View: из Song View нажми `[SHIFT]+[UP]`, выбери `LOAD`, нажми `[EDIT]`, чтобы открыть файловый браузер. См. M8 Operation Manual v6.5.2, Loading a Demo Song, стр. 9.

- [ ] Загрузи один из своих ранее завершённых треков; если начинаешь с чистого листа - демо-композицию.

- [ ] Нажми `[SHIFT]+[PLAY]`, чтобы воспроизвести всю композицию. Прослушай её до конца.

- [ ] Пока она играет, перемещайся по интерфейсу: `[SHIFT]+[DIRECTION]` переключает представления; мини-карта в правом нижнем углу показывает текущее положение.

- [ ] Открой один из инструментов композиции: в Phrase View поставь курсор на колонку инструмента `I` и нажми `[SHIFT]+[RIGHT]`, чтобы перейти в Instrument View. Посмотри параметры, но ничего не меняй.

### Начало Проекта 1

- [ ] В Project View выбери `NEW` либо загрузи чистый слот композиции. В настройках проекта дай ему имя `Project1`.

- [ ] Создай четырёхтактовый луп на трёх дорожках.

  - **Дорожка 1: барабаны.** В M8 нет понятия «kit»: один инструмент Sampler загружает ОДИН файл семпла и воспроизводит его. Используй три отдельных Sampler-инструмента.

  - Инструмент `00`: Sampler, `SAMPLE` = файл бочки `.wav` из `/Samples/` - one-shot, не нарезанная цепочка.

  - Инструмент `01`: Sampler, `SAMPLE` = файл малого барабана `.wav`.

  - Инструмент `02`: Sampler, `SAMPLE` = файл хай-хэта `.wav`.

  - На барабанной дорожке в Phrase View меняй колонку `I` по строкам, выбирая нужный звук: например, бочка в строке `00`, малый барабан в `04`, хай-хэт в `02/06`. Значение ноты оставь постоянным, например `C-4`.

  - **О нарезанных drum chain.** Если загрузить файл с несколькими ударами в один Sampler при `SLICE 00OFF`, он целиком воспроизводится с высотой, определяемой нотой, - это не то, что сейчас нужно. Для хроматического запуска слайсов понадобятся маркеры, созданные в Sample Editor режимами `AUTO` или `SILENCE`, и параметр `SLICE = FILE` в Instrument View. На неделе 1 пропусти это: тема появится на неделе 7.

  - **Дорожка 2: бас.** Используй Macrosynth с моделью по умолчанию и выбери низкую ноту примерно `C-3`.

- **Дорожка 3: мелодия.** Используй пресет Macrosynth или Wavsynth и более высокую ноту примерно `C-5`.

- [ ] В Phrase View вводи ноты в колонку `N`, оставь velocity `V` со значением по умолчанию `64`, а в `I` укажи номер инструмента.

- [ ] На этой неделе используй только пресеты. Не редактируй инструменты.

- [ ] Сохрани проект: Project View → `SAVE`.

## Линия 2: основа синтеза - осцилляторы

**Цель:** научить слух узнавать пять основных форм волны.

- [ ] Открой пустой слот инструмента и установи `TYPE = Wavsynth`. См. M8 Operation Manual v6.5.2, Wavsynth View, стр. 50.

- [ ] В Wavsynth параметр `SHAPE` переключает формы волны. См. M8 Operation Manual v6.5.2, Wavsynth Wave Table Index, стр. 82.

- [ ] Прослушай каждую форму отдельно. Оставь огибающую по умолчанию: Instrument Modulation View → `MOD1 = AHD ENVELOPE` со стандартными значениями.

- [ ] Включи `NOTE PREVIEW` в System Settings (M8 Operation Manual v6.5.2, стр. 40), затем прослушивай формы в Phrase View (M8 Operation Manual v6.5.2, стр. 14): поставь инструмент на шаг и меняй ноту комбинацией `[EDIT]+[LEFT/RIGHT]` по полутонам или `[EDIT]+[UP/DOWN]` по октавам. В Instrument View также работает `[EDIT]+[PLAY]`, но там предпросмотр всегда звучит на фиксированной низкой высоте.

- [ ] Мысленные заметки, записывать не обязательно:

  - **Sine** - чистая синусоида, саб-частоты, без гармоник.

  - **Sawtooth** - яркая пилообразная волна со всеми гармониками, классический синтезаторный бас или лид.

  - **Square** - полый звук, только нечётные гармоники, «кларнетовый» характер. В Wavsynth это `PULSE 50%`: формы с буквальным названием Square нет.

  - **Triangle** - мягкая треугольная волна, главным образом основной тон и слабые гармоники.

  - **Noise** - источник без определённой высоты для хай-хэтов, малого барабана и свипов.

## Линия 3: принцип аранжировки - распознавание напряжения и разрешения

**Цель:** натренировать слух замечать, благодаря чему электронный трек «приходит» в нужную точку.

- [ ] Выбери два-три любимых электронных трека любого жанра, желательно близких твоему вкусу.

- [ ] Один раз прослушай каждый полностью. Найди единственный момент, к которому всё строилось.

- [ ] Это может быть полный drop, вступление мелодии, внезапная тишина или звук, который наконец перестал быть заглушён. Возможен и отрицательный приход: всё исчезает.

- [ ] Пока не пытайся написать такой момент. Просто научись замечать его.

- [ ] Необязательный пример: альбом [laamaa — seven weeks](https://laamaa.bandcamp.com/album/seven-weeks), созданный на M8 и опубликованный с исходными файлами. Обрати внимание на ясную дугу каждого трека.

## Результат недели

Аранжировка в M8 создаётся в Song View: в каждой строке находится по одной chain для каждой дорожки, а playhead дорожек независимо проходит их цепочки. См. M8 Operation Manual v6.5.2, Song View, стр. 10. Chain представляет собой последовательность максимум из 16 фраз; см. M8 Operation Manual v6.5.2, Chain View, стр. 12. Теперь четырёхтактовый луп превратится в короткую аранжировку с настоящей динамикой.

- [ ] Помести луп каждой дорожки в собственную chain. В каждой колонке дорожки Song View поставь chain, воспроизводящую написанные на этой неделе четыре такта. Все chain должны иметь одинаковую длину, чтобы дорожки оставались синхронными; это прямо указано в M8 Operation Manual v6.5.2, Song View, стр. 10.

- [ ] Собери примерно 32 такта с дугой. Добавляй строки Song View, пока композиция не достигнет примерно 32 тактов, например восьми строк четырёхтактовой chain. Простая дуга определяется тем, что присутствует в каждой строке: только барабаны → добавить бас → добавить мелодию → полный состав → снова убрать элементы.

- [ ] **Выключай дорожки chain с пустыми фразами, а не mute.** Чтобы дорожка молчала в разделе и при этом оставалась синхронной с остальными, помести в её ячейку chain из пустых фраз. По традиции это chain `00` или `FE` (M8 Operation Manual v6.5.2, стр. 10); chain без нот отображается в Song View серым. Так динамика становится частью аранжировки, сохраняется вместе с ней и правильно попадает в render.

  - **Почему не кнопка mute?** Live mute/solo - `[OPTION]+[SHIFT]` / `[OPTION]+[PLAY]` в Mixer View, см. M8 Operation Manual v6.5.2, стр. 31 - это управление исполнением в реальном времени. Оно не сохраняется в структуре композиции и потому не подходит для построения разделов. Используй mute для прослушивания вариантов, но не для аранжировки.

  - **Необязательно, но полезно в растущих проектах: нумерация по колонкам.** Фразы и chain находятся в общем пуле всех восьми дорожек (M8 Operation Manual v6.5.2, стр. 12), поэтому M8 не подсказывает, какой колонке принадлежит chain. Создай подсказку сам: назначь каждой колонке Song View собственный диапазон, чтобы старшая hex-цифра сразу указывала дорожку. Колонка `00` использует `00-0F`, колонка `01` - `10-1F` и так далее. Тогда одного взгляда на номер достаточно, чтобы убедиться, что редактируется нужная колонка. Пустые (`FE`) и общие служебные chain держи в верхнем диапазоне, вне блоков дорожек. Компромисс: такая система мешает повторно использовать одну фразу или chain на разных дорожках, хотя общий пул именно это позволяет. Нарушай правило намеренно, когда нужен общий элемент.

- [ ] Перейди в Render View (M8 Operation Manual v6.5.2, стр. 47) и отрендери композицию в WAV.

- [ ] Включи сегодняшнюю дату в имя WAV-файла.
