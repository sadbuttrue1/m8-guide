# Неделя 10 — сведение и мастеринг Scope B в Ableton (необязательно)

**Эта неделя необязательна и не является моментом, когда трек становится готовым к выпуску.** Рендер Проекта 2, полученный на неделе 9, уже является файлом для доставки, который можно загружать на платформы — см. [Справочник по финализации → Выпуск рендера Scope A](../reference/finalization.md#выпуск-рендера-scope-a). Пропусти неделю, если эта версия достаточно хороша или если ты выгорел.

**Что фактически добавляет неделя 10:** надёжные измерения integrated LUFS и true peak, более точный EQ по сравнению с тремя полосами M8, обработку отдельных стемов и возможность намеренно попасть в заданную громкость, а не выбирать её только на слух.

**Цель:** провести стемы Проекта 2 через Scope B в Ableton и получить более точно обработанную версию трека, который уже можно было опубликовать.

**Время:** три занятия по 60 минут. **Жёсткие пределы.**

**Справочники:**
- [Справочник по сведению](../reference/mixing.md) → рабочий процесс Scope B.
- [Справочник по финализации](../reference/finalization.md) → мастеринг-цепь Scope B.

## Занятие 1 (около 60 минут) — рендер стемов и сведение в Ableton

### Шаг 1: рендер стемов с M8 (15 минут)

Справочник: Сведение → Scope B → Рендер стемов.

M8 выполняет это за один проход: режим `STEMS` в Render View создаёт отдельный WAV для каждой дорожки (руководство, стр.47). Не нужно восемь раз отключать дорожки и повторять рендер.

- [ ] Открой Проект 2 на M8.
- [ ] Project View → `RENDER`.
- [ ] Установи режим рендера `STEMS`, а не `MIXED`.
- [ ] `SONG ROW START` / `SONG ROW LAST`: вся композиция; `TRACKS`: включены все восемь дорожек.
- [ ] `MODFX`, `DELAY`, `REVERB`: **включены** — рендери звучание M8 вместе с send, а не необработанные осцилляторы.
- [ ] `LIMITER`: **выключен** — ограничение будет выполнено мастер-цепью на занятии 2.
- [ ] `MODE`: `32`-bit — наиболее точный экспорт, который и нужен для передачи в DAW.
- [ ] Задай `NAME` и запусти рендер. Файлы появятся в `/Renders` на SD-карте.
- [ ] Скопируй `/Renders` с карты. Получится до восьми WAV-стемов; дорожки без chain в выбранном диапазоне пропускаются.

### Шаг 2: сведение Scope B в Ableton (40 минут)

Справочник: Сведение → Scope B → Минимальное сведение в Ableton.

- [ ] Создай новый проект Ableton и импортируй все стемы на отдельные аудиодорожки.
- [ ] Опусти все фейдеры. Начни с тишины.
- [ ] Соблюдай порядок: бочка → бас → барабаны → мелодические элементы → эффекты.
- [ ] Применяй EQ на каждом стеме по тем же принципам Scope A, но с более точным EQ Ableton.
- [ ] Необязательно: bus compression группы барабанов и side-chain через компрессор Ableton.
- [ ] Сравни с одним профессиональным reference track.
- [ ] **Жёсткий предел — 40 минут.**

### Шаг 3: рендер микса (5 минут)

- [ ] Отрендери сведённый трек без мастер-цепи в WAV 44,1 кГц / 24 бита.
- [ ] Сохрани как `Project2_mixed.wav`. **На этом занятии не применяй мастеринг.**

## Занятие 2 (около 60 минут) — triage микса и master

### Шаг 1: свежее прослушивание (10 минут)

- [ ] Один раз прослушай `Project2_mixed.wav`, не делая заметок во время воспроизведения.
- [ ] После окончания запиши одну-три конкретные проблемы.

### Шаг 2: решение — triage или мастеринг как есть? (5 минут)

- [ ] 0–1 проблема: мастери как есть.
- [ ] 2–3 очевидные проблемы: выполни triage в Ableton (шаг 3).
- [ ] 4 и более: выбери две худшие либо прими текущий вариант и мастери как есть. **Не перестраивай микс.**

### Шаг 3: triage микса в Ableton (15 минут, если требуется)

- [ ] Исправь только одну-две проблемы: уровни, EQ или send.
- [ ] **Не трогай аранжировку.**
- [ ] Повтори рендер как `Project2_mixed_v2.wav`.

### Шаг 4: мастеринг Scope B (30 минут, жёсткий предел)

Справочник: Финализация → цепь Scope B.

- [ ] Создай новый проект Ableton или новую цепь и импортируй сведённый рендер.
- [ ] Импортируй reference track.
- [ ] Примени: HP filter → bus EQ → Glue Compressor → Limiter.
- [ ] Цель — около −14 LUFS или значение, подходящее жанру.
- [ ] Сравни A/B с reference: сократи разницу, не пытайся совпасть идеально.
- [ ] **Остановись через 30 минут.** Поставь таймер.

Сохрани как `Project2_master_v2.wav`.

## Занятие 3 (около 60 минут) — проверка на системах и принятие

### Шаг 1: проверка на трёх системах (30 минут)

Прослушай на:

- [ ] динамиках телефона;
- [ ] наушниках;
- [ ] ноутбуке или в автомобиле.

Сделай одну-две заметки по каждой системе.

### Шаг 2: решение (10 минут)

- [ ] Нет общей проблемы на разных системах: готово, переходи к шагу 4.
- [ ] Одна повторяющаяся проблема: разрешено одно исправление, переходи к шагу 3.
- [ ] Несколько повторяющихся проблем: прими как есть и запиши выводы на будущее.

### Шаг 3: одно разрешённое исправление (15 минут, если требуется)

- [ ] Открой проект мастеринга.
- [ ] Сделай одно изменение и повтори рендер.
- [ ] **Готово.** Больше проходов нет.

### Шаг 4: принятие и выпуск

- [ ] Переименуй финальный файл в `Project2_RELEASE.wav`.
- [ ] Если действительно выпускаешь, загрузи на Bandcamp/SoundCloud/Spotify через DistroKid или другой сервис.
- [ ] Если нет, сохрани файл там, где он не потеряется.
- [ ] Отправь нескольким людям.

## Правила против перфекционизма

- **Всего не более двух мастеринг-проходов:** занятие 2 и одно исправление на занятии 3. После этого готово.
- **Разрешены один проход сведения и один triage.** После шага 3 занятия 2 микс больше не перестраивается.
- **После занятия 3 больше не используй reference.** Не сравнивай на следующий день и не расстраивайся.
- **Плохие первые мастера и являются целью.** Выполни мастеринг 5–10 треков, прежде чем оценивать свой навык.
