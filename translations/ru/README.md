# Русская редакция M8 Learning Plan

Полный русский перевод актуальной Markdown-версии учебного плана. Структура
повторяет английский оригинал один к одному: обзор, десять недель и шесть
справочников. В редакцию включены относящиеся к плану изменения прошивок M8
6.6.0 и 6.6.1.

Базой перевода служит ветка `main` на коммите `eeae891`. При обновлении
оригинала перевод следует синхронизировать по правилам из корневого
`CLAUDE.md`: сохранять все задачи, ссылки, ссылки на руководство, ограничения
по времени и структуру разделов.

## Сборка PDF

Из корня репозитория:

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python build_pdf.py --lang ru
```

По умолчанию будет создан файл `translations/ru/M8_Learning_Plan_RU.pdf`.
Готовый PDF не хранится в Git: он собирается из Markdown единым скриптом
`build_pdf.py` и исключён через `.gitignore`.
