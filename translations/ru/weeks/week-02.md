# Неделя 2 - LFO на фильтр: слоты модуляции и таблицы

**Цель:** разобраться в системе модуляции. Понять разницу между слотами модуляции - это уровень инструмента и самый чистый способ использовать LFO - и таблицами, которые дают пошаговую автоматизацию для задач, недоступных слотам.

Главное открытие недели: прежде чем понадобятся таблицы, каждый инструмент M8 уже имеет четыре специальных слота модуляции. Для задачи «LFO на фильтр» слот модуляции обычно является правильным инструментом. Таблицы нужны для ступенчатой автоматизации, арпеджио и многостадийных огибающих - того, что слоты не выполняют столь же чисто.

**Ссылки:** M8 Operation Manual v6.5.2 - Instrument Modulation View (стр. 18), Modulation Types: LFO (стр. 20-21), Table View (стр. 24), Macrosynth (стр. 52), Effect Command Help View (стр. 48).

## Линия 1: техника M8 - два способа направить LFO на фильтр

### Способ A: слот модуляции - рекомендуется для LFO > filter

Это чистый и естественный для M8 способ.

- [ ] Открой басовый инструмент Проекта 1. Убедись, что `TYPE = Macrosynth`. См. M8 Operation Manual v6.5.2, стр. 52.

- [ ] В Instrument View у Macrosynth есть раздел параметров `FILTER` с `CUTOFF` и `RES`. Установи сравнительно низкий `CUTOFF`, примерно `40`, чтобы LFO было куда открывать фильтр.

- [ ] Из Instrument View нажми `[SHIFT]+[UP]` и перейди в Instrument Modulation View. См. M8 Operation Manual v6.5.2, стр. 18.

- [ ] Ты увидишь четыре слота `MOD1-MOD4`. В каждом есть `TYPE`, `DEST` и собственные параметры.

- [ ] Настрой `MOD1`:

  - тип `MOD1`: `LFO`;

  - `DEST`: `FILTER CUTOFF`, выбирай комбинацией `[EDIT]+[DIRECTION]`;

  - `AMT`: для начала `40` в диапазоне `00-FF`; это глубина модуляции;

  - `OSC`: `TRI` - треугольник, плавная классическая форма LFO; другие формы перечислены в M8 Operation Manual v6.5.2, стр. 21;

  - `TRIG`: `FREE` - LFO непрерывно повторяется и не сбрасывается каждой нотой; варианты: `FREE/RETRIG/HOLD/ONCE`;

  - `FREQ`: `08`; для `OSC`, не работающего в tick-режиме, значение задаётся шагами шестнадцатых нот.

- [ ] Прослушай комбинацией `[EDIT]+[PLAY]`. Услышь, как фильтр медленно открывается и закрывается.

- [ ] Поэкспериментируй: `FREQ = 04` быстрее, `10` медленнее; `OSC = SIN` плавнее, `SQU DN` даёт gate-эффект. Подбери `AMT` по вкусу.

### Генеративный бонус: формы RANDOM и DRUNK

Полный контекст находится в [Справочнике по генеративным приёмам](../reference/generative.md#2-формы-lfo-random--drunk).

- [ ] На том же инструменте выбери `OSC = DRUNK`. Фильтр блуждает органично и никогда не повторяется совершенно одинаково.

- [ ] Затем выбери `OSC = RANDOM`. Значения меняются ступенчато и скачкообразно в каждом цикле.

- [ ] Обе формы официально описаны среди LFO в M8 Operation Manual v6.5.2, стр. 21.

- [ ] Они подходят всякий раз, когда параметр должен ощущаться живым, а не механическим: pads, развивающиеся текстуры, саунд-дизайн.

- [ ] Следи за глубиной: слишком высокий `AMT` превращает движение в хаос. Тонкие значения `20-40` обычно полезнее драматических.

### Способ B: табличный «ручной LFO» - для ступенчатого и синхронного управления

Этот вариант использует таблицу. Выбирай его, если каждому шагу фразы требуется явно заданное значение фильтра, а не плавная автоматизация.

- [ ] Оставайся на басовом инструменте. Из Instrument View нажми `[SHIFT]+[RIGHT]`, чтобы открыть Table View. См. M8 Operation Manual v6.5.2, стр. 24.

- [ ] Таблица состоит из 16 строк с колонками `N` (transpose), `V` (volume) и тремя колонками FX.

- [ ] Чтобы открыть справку по FX-командам, поставь курсор на колонку FX и нажми `[EDIT]+[UP]` либо `[EDIT]+[DOWN]`. Откроется Effects Command Help View. См. M8 Operation Manual v6.5.2, стр. 48.

- [ ] Cutoff фильтра - специфический параметр Macrosynth. Команда FX для него находится в Instrument FX Commands, M8 Operation Manual v6.5.2, стр. 75. Найди команду фильтра Macrosynth через встроенный Effect Command Help View.

- [ ] С помощью показанной справкой команды создай четырёхшаговый ступенчатый свип фильтра. Примерные значения ниже служат лишь иллюстрацией; используй фактический код команды, показанный M8:

  - строка `00`: cutoff = `20`;

  - строка `01`: cutoff = `50`;

  - строка `02`: cutoff = `80`;

  - строка `03`: cutoff = `50`.

- [ ] Скорость таблицы задаётся `TABLE TIC` в Instrument View. Стандартное `01` означает один tick на строку.

  - Одна строка фразы равна **6 тикам**, поэтому `TIC 01` перемещает таблицу шесть раз за строку — намного быстрее, чем кажется. `TIC 06` даёт одну строку таблицы на строку фразы. См. [Справочник по таймингу](../reference/timing.md).

- [ ] Сравни: LFO в слоте движется плавно и непрерывно; таблица ступенчата и привязана к скорости tick. Выбери вариант, подходящий звуку.

### Совет

Используй браузерный [M8 table editor](https://twinside.github.io/m8table/), чтобы сначала поэкспериментировать с построением таблицы, а затем перенести её в устройство.

## Линия 2: основа синтеза - огибающие ADSR

**Цель:** понять, что форма огибающей определяет характер инструмента сильнее, чем осциллятор.

Instrument Modulation View управляет и огибающими. Те же слоты модуляции могут содержать `LFO`, `AHD`, `ADSR`, `DRUM`, `TRIG` или `TRACKING`. См. M8 Operation Manual v6.5.2, стр. 18-21.

- [ ] Открой новый инструмент Wavsynth или Macrosynth.

- [ ] В Instrument Modulation View установи `MOD1 = ADSR ENVELOPE`, а `DEST = VOLUME` или `AMP`.

- [ ] Настрой ADSR по M8 Operation Manual v6.5.2, стр. 20:

  - `AMT` - глубина и направление действия огибающей; задай его первым. Для громкости используй положительное значение, `7F` = полная глубина.

- `ATK` (attack) - время достижения `AMT`;

  - `DEC` (decay) - время перехода к sustain;

  - `SUS` (sustain) - уровень удержания, пока звучит нота;

  - `REL` (release) - время затухания до нуля после окончания ноты.

- [ ] **Pluck:** `AMT=7F`, `ATK=00`, `DEC=20`, `SUS=00`, `REL=10`. Звук ударный и резкий.

- [ ] **Pad:** `AMT=7F`, `ATK=60`, `DEC=00`, `SUS=7F`, `REL=80`. Тот же осциллятор превращается в совершенно другой инструмент.

- [ ] Осознай: attack и release выполняют около 80% работы по определению характера звука.

### Почему AMT разделяется на значении 80

`AMT` - биполярное, то есть знаковое значение, а не шкала от `00` до максимума. Поэтому интерфейс визуально разделён в точке `80`:

- `00-7F` - положительная величина: `00` = нет модуляции, `7F` = +127, полная глубина;

- `80-FF` - отрицательная величина: `80` примерно соответствует самому сильному отрицательному значению, `FF` примерно -1.

При прокрутке дальше `7F` направление модуляции переворачивается, а не становится глубже. Читай `AMT` как ответ на два вопроса: насколько далеко и в какую сторону огибающая толкает назначение.

- [ ] Для обычной огибающей громкости оставляй `AMT` положительным: `7F` - полная глубина. Поэтому и Pluck, и Pad выше используют `AMT=7F`.

- [ ] Отрицательный `AMT` для громкости инвертирует огибающую: чем выше её значение, тем тише звук. Получается ducking/gate. Это осознанный эффект, а не стандартная форма амплитуды.

- [ ] Отрицательная глубина полезнее для `CUTOFF`, когда огибающая закрывает фильтр, или `PITCH`, когда нужен нисходящий dive у бочки либо zap.

- [ ] Типичная ошибка: оставить `AMT=00`, отчего огибающая ничего не делает, либо случайно попасть в диапазон `80+`, получить инверсию и не понимать, почему форма действует наоборот. Hex-логика такова: «отрицательная громкость» бессмысленна, но отрицательное **изменение** громкости возможно; поэтому величины модуляции имеют знак. См. M8 Operation Manual v6.5.2, стр. 21, и The M8 Companion, §2.4.

### Аналогия с гитарой

То, как нота начинается - удар медиатором, tapping или подъём ручкой громкости - и как затухает - palm mute либо полное sustain, - определяет тембр сильнее, чем выбор подключённой гитары. Здесь действует тот же принцип.

## Линия 3: принцип аранжировки - контраст A/B

**Цель:** создать в Проекте 1 две отчётливо различающиеся части.

- [ ] Добавь в Проект 1 раздел B. Как и A, он представляет собой блок строк Song View, охватывающий все дорожки, а не отдельную ячейку. Прокрути вниз за строки недели 1 к пустым ячейкам и построй B там.

  - Дорожка, которую ты меняешь, получает новую chain: в её пустой ячейке `[EDIT]` вставляет chain, а двойное `[EDIT]+[EDIT]` создаёт свежую пустую chain для заполнения. См. M8 Operation Manual v6.5.2, стр. 11.

  - Дорожки, продолжающиеся без изменений, просто повторно используют свои chain части A в строках B.

  - Дорожка, которая должна исчезнуть, получает пустую chain или `FE` - тот же динамический приём, что на неделе 1.

- [ ] B отличается от A **ровно одним конкретным способом**, а не всем сразу.

- [ ] Выбери один вариант:

  - в разделе B исчезают барабаны;

  - вступает новый мелодический элемент, отсутствующий в A;

  - фильтр баса открывается полностью за счёт глубины LFO или изменения transpose у chain;

  - меняется тональность: используй колонку `TSP` в Chain View, она транспонирует по полутонам.

- [ ] Прими одно решение. Если начинаешь добавлять второе изменение, отмени его.

## Результат недели

- [ ] В Song View Проекта 1 теперь есть разделы A и B.

- [ ] В басовом инструменте работает либо LFO фильтра из слота модуляции, либо табличный свип - на твой выбор.

- [ ] Хотя бы один инструмент имеет намеренно созданную ADSR, а не стандартную огибающую.

- [ ] Композиция длится не менее примерно 48 тактов: около 32 тактов A - примерно восемь строк Song View с четырёхтактовой chain - и около 16 тактов B, то есть ещё примерно четыре строки. Измеряй тактами, а не секундами: темп меняет ход часов, но не аранжировку. При 120 BPM одна только часть A уже занимает около 64 секунд.

- [ ] Отрендери WAV в Render View. См. M8 Operation Manual v6.5.2, стр. 47.
