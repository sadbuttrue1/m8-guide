# Week 9 — Finalize and ship Project 2

**Goal:** Take Project 2 from draft (Week 8) to mixed, finalized, shipped. Second release-ready M8 track in this cycle.

**Combines mix + finalization in one week** (vs Project 1 which had separate weeks). You have the skills now — this is application speed, not learning speed.

**References:**
- [Mixing Reference](../reference/mixing.md) for Scope A mix
- [Finalization Reference](../reference/finalization.md) for Scope A master

**Time-box:** 3 sessions, 60 min each.

---

## Session 1 (~60 min) — Scope A mix pass

Follow the full Mixing Reference Scope A workflow:

- [ ] Step 1: Solo kick, set baseline volume
- [ ] Step 2: Add bass, balance against kick (side-chain if needed)
- [ ] Step 3: Add drums as a kit
- [ ] Step 4: Add melodic elements with appropriate depth (reverb/delay sends)
- [ ] Step 5: Full mix listen on 2 systems
- [ ] **Hard time limit: 60 min.** Mix is done when nothing obvious is wrong on 2 systems.

### Note

Project 2 should mix faster than Project 1 because your `EG-*` instruments are pre-EQ'd from Week 7. If you're spending more than 60 min, the issue is likely in the instruments or the arrangement, not the mix.

---

## Session 2 (~60 min) — Scope A finalization

Follow the Finalization Reference Scope A workflow:

- [ ] Pre-master mix verification (10 min)
- [ ] Main mix EQ — high-pass at 30Hz, gentle tone shaping (10 min)
- [ ] OTT compression (5 min)
- [ ] Limiter — 2–4dB compression on peaks (10 min)
- [ ] Render to WAV (5 min)
- [ ] First listen, fresh ears (20 min)

Save as `Project2_master_v1.wav`.

---

## Session 3 (~60 min) — Multi-system check + ship

### Step 1: Three-system listening test (20 min)

- [ ] Phone speakers
- [ ] Headphones
- [ ] Laptop speakers or car

1–2 notes per system.

### Step 2: One allowed fix (15 min, only if needed)

Problems on 2+ systems consistently?
- [ ] If no: done. Skip to Step 3.
- [ ] If yes, one issue: one fix allowed. Re-render.
- [ ] If yes, multiple issues: ship as-is. Note for next cycle.

### Step 3: Release check (10 min)

Same as Week 6 — Project 2 gets a release-grade file off the M8 too, no DAW involved. Full context: [Finalization Reference → Releasing a Scope A render](../reference/finalization.md#releasing-a-scope-a-render).

- [ ] Limiter & Mix Scope View → `PEAK`, clear with `[OPT]+[EDIT]`.
- [ ] Play the loudest section. Read `PEAK`. **Target around `-1.0 dB`.**
- [ ] Too hot? Pull `MIX` down, not `LIM` — `MIX` sits *after* the limiter (manual p.34).
- [ ] Re-render `MIXED`, `LIMITER` **on**, `MODE` `32`-bit. That file is uploadable as-is; re-render at `16` only if a distributor rejects it.

### Step 4: Ship it (15 min)

- [ ] Rename: `Project2_FINAL.wav`.
- [ ] Send to at least one person outside your ears.
- [ ] Optional: post somewhere (Bandcamp unlisted, Soundcloud private, Discord) — doesn't need to be public.
- [ ] If you want it on streaming: this file goes straight to a distributor. Week 10 is not a prerequisite.

## Anti-perfectionism rules

- **Two passes max total** (master + one allowed fix).
- **No comparing Project 2 to Project 1.** They're not the same kind of work.
- **The improvement from Project 1 to Project 2 is the win**, not absolute quality.
- **Ship even if you don't love it.** Two shipped tracks in ~9 weeks is a real achievement. Quality compounds with quantity.
