## Thread 1: M8 technique — Apply everything

### Setup (Session 1, 60 min)

- [ ] In Project View, create a new project. Name it `Project2`.
- [ ] In Instrument Pool View, load 4–6 of your `EG-*` instruments from Week 7. **No factory presets.** This is the test.
- [ ] Don't choose all 10 — constraint forces creativity.
- [ ] Set tempo in Project View. Pick and commit.
- [ ] Build a 4-bar A section: drums + bass + 1–2 melodic elements.

### Build out (Sessions 2–3, 60 min each)

- [ ] Build a B section with intentional contrast (one specific change, not five).
- [ ] Chain A and B into a song structure in Song View.
- [ ] **Apply at least one of each accumulated technique:**
	- LFO via modulation slot OR table-based stepped automation (Week 2)
	- `PIT` slide somewhere (Week 3)
	- Tracking modulation on at least one drum (Week 3)
	- `ARP` or retrigger somewhere (Week 4)
	- A designed transition between sections (Week 4)
- [ ] **Optional generative shortcut for melody:** if you're stuck writing melodic content, try tables as arpeggiators. See [Generative Toolkit Reference](../reference/generative.md) → #6.
	- On a melodic instrument, set `TABLE TIC` to a fast value (`02` or `04`).
	- In the table's N column, write a sequence: `00`, `04`, `07`, `0C`, `07`, `04` (major arp up and down).
	- Trigger ONE note in Phrase View. The table plays the arp.
	- Faster than writing every note. Great when you want movement but lack inspiration.
- [ ] Don't force all of them. Use what fits.
- [ ] Aim for ~88 bars / ~22 rows total. (Time Stats View, p.46, shows the running time to cross-check — ≈3 min at 120 BPM.)

### Structure target

- Rough shape: intro → A → B → A' → B' → outro. Gentle development style applies.
- Not pop verse/chorus. A+B style with drops/risers is the goal.

## Thread 2: Synthesis fundamental — Effects as sound design

*Goal: realize effects aren't polish, they're instrument character.*

The M8 has 3 send effects: ModFX (chorus/phaser/flanger), Delay, Reverb (manual p.36–37).

- [ ] Take one of your `EG-*` instruments. Set its `REV` send high (~`80`).
- [ ] In Effect Settings View (`[SHIFT]+[DOWN]` from Mixer View), set Reverb SIZE high, DECAY long.
- [ ] Hear: ambient, distant, atmospheric. Different instrument.
- [ ] Take another. Set its `DEL` send. Delay TIME = `40` (4 beats), FEEDBACK ~`60`.
- [ ] Hear: rhythmic doubling, more space.
- [ ] In Project 2: at least **one element wet and one element dry**. Contrast.

## Thread 3: Arrangement — THE ARRIVAL

*This is the week the meander problem gets fixed.*

### Decide before you start

- [ ] **Before writing any notes** in Project 2: decide where the arrival point is. Most likely around bar 52–68 (≈rows 13–17) of an ~88-bar track — roughly two-thirds through.
- [ ] Decide WHAT happens at the arrival. Pick one:
	- The full beat finally drops (kick + everything in)
	- A melodic element finally enters
	- Everything drops out except one element (negative arrival)
	- Filter fully opens on a sound that's been muted/restricted
	- A new key/transpose hits via Chain View `TSP`
- [ ] Write toward that moment from the start.

### Self-check during the week

Every section asks one of two questions:
- **Before the arrival:** *Am I building toward it?* Increasing tension, adding elements, raising filter, building energy.
- **After the arrival:** *Am I releasing the energy that built?* Releasing tension, removing elements, lowering filter, dissipating.

If a section answers "no" to both, that section is the problem. Cut it or rebuild it.
